# Cumbre — Guía de Senderismo España

MVP de una aplicación de senderismo personalizada para España.

## Incluido
- Recomendación por nivel (Principiante / Intermedio / Experto).
- Explorador y buscador de rutas.
- Registro local de rutas completadas y XP durante la sesión.
- Progresión de nivel.
- Área de comunidad preparada para fotos y avisos del sendero.
- Módulo SOS: geolocalización del dispositivo, coordenadas, precisión, llamada al 112 y compartir ubicación.
- Diseño responsive para móvil y escritorio.

## Importante sobre SOS
La aplicación no afirma ni garantiza que el 112 reciba automáticamente la posición. El módulo facilita obtener/compartir coordenadas y realizar la llamada. La integración futura con servicios oficiales deberá validarse con las autoridades y plataformas correspondientes.

## Desarrollo
```bash
npm install
npm run dev
```
